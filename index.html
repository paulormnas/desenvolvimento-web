Sobre a Disciplina

O que você vai aprender e por que é fundamental para a Segurança Cibernética

Fundação Web

Construir a base sólida do frontend. Compreender a renderização no navegador, o ciclo de vida do DOM e as requisições assíncronas.

Desenvolvimento Seguro

Aprender como falhas comuns de segurança (como XSS, injeção de tags, vazamento de tokens no frontend) nascem e como mitigá-las na raiz.

Automação & Cloud

Publicar projetos reais em redes CDN globais usando esteiras de CI/CD automatizadas a partir do seu repositório no GitHub.

Stack Tecnológica

As tecnologias pilares do desenvolvimento web moderno que estudaremos

HTML5

Estrutura e semântica de dados. Elementos cruciais para acessibilidade e SEO.

CSS3

Estilização avançada, Flexbox, Grid Layout, responsividade para telas de todos os tamanhos.

JavaScript

Lógica de programação, manipulação do DOM e comunicação assíncrona com APIs externas.

CI/CD & Deploy

Deploy de arquivos estáticos integrados ao git usando Vercel, Netlify e GitHub Pages.

Cronograma do Curso

Navegue pelo conteúdo programático de cada semana de aula

Introdução ao funcionamento da Internet, protocolo HTTP/HTTPS, modelo cliente-servidor e a arquitetura das páginas web básicas.

  • Funcionamento do DNS e servidores de arquivos
  • Anatomia de uma requisição e resposta HTTP
  • O que é HTML, CSS e JS sob a perspectiva do navegador

Primeiros passos na criação da estrutura de páginas usando tags estruturais básicas, links e formatação de textos.

  • Tags fundamentais: h1-h6, p, a, strong, em
  • Criação de listas ordenadas e não ordenadas
  • Atributos HTML: href, target, src, alt

Melhorando a exibição de informações complexas e ricos formatos de mídia. Introdução à semântica estrutural.

  • Tabelas complexas (thead, tbody, tr, td, th)
  • Incorporação de mídias: audio, video e iframe
  • HTML Semântico (header, nav, main, article, section, footer)

Estilizando as estruturas criadas. Selecionando elementos com precisão e aplicando estilos visuais fundamentais.

  • Sintaxe CSS, Inline vs Internal vs External CSS
  • Seletores básicos: tag, classe (.class), id (#id) e combinadores
  • Cores (RGB, HSL, Hexadecimal) e tipografia (font-family, size, weight)

Como os elementos se posicionam na tela. O modelo de caixa do navegador e sistemas de grid e flexbox.

  • Margin, Padding, Border e Box-sizing: border-box
  • Posicionamentos (static, relative, absolute, fixed)
  • Introdução prática a Flexbox e CSS Grid

Criando sites que se adaptam a smartphones, tablets e desktops de forma fluida. Uso de variáveis CSS.

  • Media Queries (@media) e breakpoints
  • Unidades relativas (rem, em, vw, vh, %)
  • Custom Properties (variáveis CSS) para reusabilidade

Dando inteligência e dinamismo à página web. Variáveis, lógica condicional e loops.

  • Sintaxe JavaScript, let, const e escopo
  • Condicionais (if/else, switch) e laços (for, while)
  • Declaração e invocação de funções simples

Conectando o JavaScript com o HTML. Capturar cliques, alterar textos e estilos da página em tempo real.

  • querySelector e querySelectorAll
  • addEventListener (click, submit, input, keydown)
  • Alterando classes CSS dinamicamente com classList

Conectando sua aplicação a serviços externos na internet para carregar dados dinâmicos de forma assíncrona.

  • Formato JSON (JavaScript Object Notation)
  • Chamadas com Fetch API, promises, async/await
  • Tratamento de erros em requisições de rede

Publicando o seu código na internet de forma automatizada e com as melhores práticas de esteira de integração.

  • Ciclo de vida de software: Dev, Staging e Produção
  • Deploy estático no GitHub Pages e Vercel
  • O que é CI/CD e como automatizar deploys via Git Pushes
