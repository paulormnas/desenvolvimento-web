# Por que usar Node.js no Desenvolvimento Web?

As vantagens de unificar o ecossistema.

<v-clicks>

- **Uma Linguagem Única:** JavaScript no Frontend e no Backend (Full Stack JS).
- **Velocidade de Desenvolvimento:** Bibliotecas prontas para quase tudo no NPM.
- **Escalabilidade:** Excelente para aplicações de tempo real (Chats, Streaming, Colaboração).
- **Grande Comunidade:** Suporte massivo e documentação abundante.

</v-clicks>
