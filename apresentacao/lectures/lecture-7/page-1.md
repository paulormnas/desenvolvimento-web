# Node.js: O Motor por Trás do Backend Moderno

Node.js é um ambiente de execução JavaScript **open-source**, **cross-platform**, que permite executar código JavaScript fora de um navegador web.

- **V8 Engine:** Utiliza o motor de alto desempenho do Google Chrome.
- **Event-Driven:** Baseado em eventos e I/O não bloqueante.
- **Ecossistema:** NPM (Node Package Manager) é o maior registro de software do mundo.
