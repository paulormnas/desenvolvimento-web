# Single Page Applications (SPA)

O conceito que revolucionou a experiência do usuário.

Diferente do modelo tradicional (MPA), onde cada clique carrega uma nova página HTML do servidor:

<div class="grid grid-cols-2 gap-8 mt-6">
  <div class="p-4 border border-white/10 rounded bg-gray-800/30">
    <h3 class="text-sm font-bold mb-2">Multipage (Tradicional)</h3>
    <ul class="text-xs space-y-2">
      <li>❌ Tela pisca a cada clique.</li>
      <li>❌ Servidor gera o HTML todo vez.</li>
      <li>❌ Navegação mais lenta.</li>
    </ul>
  </div>
  <div class="p-4 border border-blue-500/30 rounded bg-blue-500/10">
    <h3 class="text-sm font-bold mb-2 text-blue-400">Single Page (SPA)</h3>
    <ul class="text-xs space-y-2">
      <li>✅ Carrega o HTML apenas uma vez.</li>
      <li>✅ Atualiza apenas o conteúdo necessário.</li>
      <li>✅ Sensação de App nativo (fluidez).</li>
    </ul>
  </div>
</div>

<div class="mt-8 text-center">
  <p class="text-sm">O React é a ferramenta perfeita para gerenciar essas trocas de conteúdo dinâmicas.</p>
</div>
