# O que torna o React Especial?

React não é um framework, é uma **biblioteca**. Ele foca exclusivamente na camada de visualização (View).

- **Declarativo:** Você descreve *o que* quer na tela, e o React cuida de *como* atualizar.
- **Baseado em Componentes:** Construa peças pequenas que, juntas, formam uma interface complexa.
- **Virtual DOM:** Uma cópia leve do DOM real que permite atualizações ultra-rápidas.
- **Aprenda uma vez, escreva em qualquer lugar:** React Native permite criar apps móveis com o mesmo conhecimento.
