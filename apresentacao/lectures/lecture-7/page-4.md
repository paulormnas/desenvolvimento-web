# Do jQuery aos Frameworks Modernos

O desenvolvimento web mudou drasticamente nos últimos 15 anos.

| Era | Tecnologia Principal | Característica |
| --- | --- | --- |
| **Estática** | HTML / CSS Puro | Páginas fixas, pouco dinamismo. |
| **DOM Manipulation** | jQuery | Manipulação manual e direta do DOM. |
| **MVC Frontend** | AngularJS / Backbone | Tentativa de organizar código em grandes apps. |
| **Componentes** | React / Vue / Svelte | UIs baseadas em peças reutilizáveis e estados. |

<div class="mt-8 text-center opacity-60 text-sm">
  A complexidade das interfaces modernas exigiu ferramentas mais robustas.
</div>
