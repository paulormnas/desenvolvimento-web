# 🛠️ Projeto Prático: DevFinder

Vamos ver tudo isso funcionando junto?

Confira a pasta `exemplos/github-explorer` para uma aplicação completa que utiliza:

- **Vite** como build tool.
- **Axios** para buscar usuários do GitHub.
- **useState** para gerenciar a busca e os resultados.
- **React Router** para navegação entre Início e Sobre.
- **Props** para passar dados ao card de usuário.
